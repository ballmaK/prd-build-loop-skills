## 约定

1. 新内容优先放 `docs/training/`（讲义 / 实操）或 `docs/briefings/`（幻灯片）  
2. 保持不限工具（Cursor / OpenCode / 其他均可）  
3. 每一期尽量具备：说明文档、教练脚本、学员可带走的大纲或幻灯片  
4. 完成一轮后开 PR 合入 `main`  
5. 优先中文话术；技能原名可以放注释小字  
6. 优先场景驱动：先讲手头状态和坑，再讲路径与产物  
7. 文稿交付前可用 `humanizer-zh` 做去 AI 味润色  
8. 口播优先「现状 / 目标态」；首次可对照 As-Is / To-Be；路径名保持英文
