# PulseNotes · 场景原料（故意不完整）

> 培训用。**不要**把它当成可直接实现的完整 PRD。  
> 目的：逼出 grilling / prd-author 的提问。

## 一句话

我希望有个叫 **PulseNotes** 的东西，每天能随手记一下自己的状态。

## 我想到的功能（未经推敲）

- 能写一条“今天怎么样”
- 最好能看到历史
- 也许能标签？开心 / 疲惫 / 专注 之类
- 以后或许要登录，多人？不确定
- UI 好看一点就行，技术栈你们看着办
- 尽快能用

## 明确不想要的？（没想清楚）

- 好像不做社交饋赠
- 不做复杂报表？也许要周报汇总？再说

## 约束

- 单人本地使用优先
- 希望有测试，别太脆弱
- 今天培训只做最小能演示的一竖切也行

## 你已知的事实（可写进仓库）

无。仓库是空的（绿场）或只有 `legacy/`（棕地 station）。

## 教练提示（学员勿依赖）

应被挑战出来的决策示例：单用户 vs 多用户、存储介质、标签枚举 vs 自由文本、是否要编辑/删除、非目标是否包含周报/协作、验收标准如何可测。
