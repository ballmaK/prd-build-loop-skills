# 一期 · 三个开工场景分享

> 定位：**场景分享 + 讨论**，不是技能名背诵。  
> 目标：听完能判断自己属于哪类场景，并知道第一步该产出什么。

## 材料

| 文件 | 用途 |
| ---- | ---- |
| [`FACILITATOR.md`](./FACILITATOR.md) | 分享人脚本与时间安排 |
| [`OUTLINE.md`](./OUTLINE.md) | 详细大纲（可当讲义） |
| [幻灯片](../../briefings/matt-theory-share/index.html) | 现场投影用 |

## 三条主线

1. **场景 1**：全新项目，需求 / PRD 还不明确  
2. **场景 2**：在建项目，已有部分功能与存量代码，如何续接  
3. **场景 3**：老旧项目改造，缺需求、缺文档  

## 建议时长

**50～60 分钟**（含讨论）；压缩版约 **45 分钟**。

## 听完应该能做到

1. 用一句话描述自己当前属于哪个场景  
2. 说出该场景的「禁忌起手」和「推荐第一步产物」  
3. 理解：挑战门 / 逆向签核之后，才进入循环实现  
4. 知道三条路最终都汇合到「可挑战的 To-Be + 反馈环」
