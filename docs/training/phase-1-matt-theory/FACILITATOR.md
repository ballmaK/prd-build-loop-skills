# 一期分享 · 教练 / 分享人脚本

## 开场（2 分钟）

> 今天不讲某家 IDE 按钮，也不写代码。  
> 我们一起把 **Matt Pocock Skills** 当作一面镜子：看清 AI 写代码为什么翻车，以及落地时该先稳住哪些纪律。  
> 下几期再动手；这一期先让脑子有地图。

投影：`docs/briefings/matt-theory-share/index.html`

---

## 时间盒（45 + 10）

| 分钟 | 板块 | 你强调的一句话 |
| ---- | ---- | -------------- |
| 0–5 | 为什么需要流程 | 快 ≠ 能交 |
| 5–15 | 四类翻车 | 错位最致命 |
| 15–22 | 两类技能 | 编排 vs 纪律 |
| 22–32 | 开心路径 | grill → spec → tickets → tdd |
| 32–40 | 和我们怎么接 | Matt 是地基，编排在其上 |
| 40–45 | 带走三句话 + 预告二期 | 先对齐，再动手 |
| 45–55 | Q&A | 用问题深化，不展开装环境细节 |

---

## 互动点（建议至少做 2 个）

1. **共鸣投票**：四类翻车里你上周中了哪一类？举手。  
2. **对比演示（口头）**：同一需求「自由发挥」vs「先 grill 再写」差在哪。不必真开 Agent，口述后果即可。  
3. **速记**：请每人在笔记写下一句「我回去会先用的一个 Matt 技能名」。

---

## 不要讲深的坑（留给二/三期）

- 各 Agent 的具体安装路径差异（只点到 `--agent`）
- PulseNotes 实操步骤
- As-Is / 棕地细节（一笔带过即可）
